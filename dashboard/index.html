How implied value is computed

implied = round( tvl_usd × 0.20 × (1 + clamp(change_7d, −50, 100) / 100 × 0.70) × (0.55 + min(age_days, 1460) / 1460 × 0.45) × (1 + 0.04 × min(chains, 5)) )

TVL is the size of the record so far; seven-day growth is its direction; tenure is how long the protocol has run with no token (unknown age counts as 180 days); breadth is how many chains the record spans. The same function scores every row and no name is special-cased. Whole-dollar ties are written one dollar apart so the board is strictly decreasing from rank 1 to rank 200. Live-token protocols are set aside with their market caps — the market's own number, never a model number. An implied value is a model, not a price and not a promise of a token.
